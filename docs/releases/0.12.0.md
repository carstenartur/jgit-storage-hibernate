# 0.12.0 — Oracle support alongside Microsoft SQL Server

This release adds an explicitly tested Oracle backend for the Core, Search and
Security library modules. Microsoft SQL Server remains officially supported with
its existing migration, repository, Search and Security coverage.

## Oracle support

- New module-owned Flyway streams start at 0.12.0, exposed through each module's
  public `ORACLE_LOCATION` constant and separate history table.
- Oracle Free 23.26.3 with AL32UTF8/AL16UTF16 is the qualified database
  configuration. The initial schema uses native SQL BOOLEAN and does not promise
  compatibility with Oracle 19c/21c or arbitrary pre-existing Oracle schemas.
- Core covers repository migration/validation, durable writes and reflog replay,
  transfer, reopening and concurrent maintenance behavior.
- Search covers Oracle NCLOB mappings, structured and Lucene queries, Unicode
  and long text, projection maintenance and persistent reopening.
- Security includes the current policy, credential/token and audit schema, with
  Oracle-specific conditional uniqueness for managed policy ownership.
- Spring Boot automatically selects Oracle migrations for Core and optional
  Search. Security migration remains an application/deployment responsibility.

The provider uses `JgitOracleDialect` to respect Oracle's nationalized text limits.
Applications constructing their own Hibernate factory should follow the
[Oracle deployment guide](../operations/oracle.md#hibernate-and-spring-boot).

## Qualification and integration boundaries

Oracle and Microsoft SQL Server run in the ordinary Docker-enabled Maven build.
CI and real releases require non-skipped passing test reports for the database
contracts and retain the evidence. Existing backend migrations remain unchanged.

This release expands the library's database coverage. A consumer's supported
configuration is still limited by the library version, modules and integration
that it actually uses and tests. The supplied standalone server image remains a
PostgreSQL deployment.

The feature release is 0.12.0 because the preceding release line is 0.11.x;
0.9.0 would be a lower version. The next development version is 0.12.1-SNAPSHOT.
